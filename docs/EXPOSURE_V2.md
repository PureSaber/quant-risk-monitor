# 暴露定义 v2：实现、使用和验收

这是独立实现的公开因子定义，不是 MSCI Barra 的专有描述子或权重。
默认仍为 v1。v2 将必须修正的口径问题与需要实验决定的新增描述子分开，
方便回退、逐项对照和保留未通过统计验收的研究结果。

## 已实现的定义

| 部分 | v2 行为 |
| --- | --- |
| 非线性规模 | 对标准化后的 log 市值取三次方，剔除规模和截距，去极值后再次剔除控制项并标准化；换算市值单位不改变暴露 |
| Beta / 残差波动率 | 252 个交易日窗口，至少 126 个股票与市场同时有效的观测；协方差和两个方差使用完全相同的配对样本，滞后一个交易日 |
| 流动性候选 | 21/63/252 日平均换手率的对数，各描述子先标准化，再等权合成；每个窗口至少 90% 的观测有效 |
| 成长候选 | 连续三个已公告年度的收入、归母利润：线性斜率除以年度值绝对值的均值；不把亏损公司当作无效，零分母保留缺失 |
| 残差波动率候选 | 252 日日收益标准差、12 个累计 21 日区间的收益范围、配对回归残差标准差；分别标准化后等权，再对规模/Beta 正交化 |
| 可用成长组合 | 收入和利润都存在时等权；只有一个可用时按剩余权重归一；两者都没有时，才按显式配置补最终成长暴露 |

累计区间收益范围要求完整 252 个交易日，不压缩停牌或缺失日期。所有价格描述子
滞后一个交易日；原始行情、复权方法、交易日历和换手率分母仍是调用方的数据契约。

财务输入必须携带 `available_at`，修订只从公开时间起生效。年度指标最多使用距报告期末
550 日的数据；不足连续三年、过期、零分母分别记录质量原因。标准化和行业中位数
都只使用当时可用的截面。可用组合不会填造原始收入；每只股票记录实际使用的描述子、
原始可用权重比例和最终暴露的填补对象。补值不是已观测财务事实。

## 接口

```python
from quant_risk_monitor import (
    public_equity_style_config,
    paired_market_descriptors,
    additional_market_descriptors,
    annual_growth_descriptors,
    DailyExposureStore,
)

config = public_equity_style_config(
    historical_industry_names,
    definition_version="v2",
    enhancements=("growth", "residual_volatility"),
    available_growth=True,
    missing_policy="industry_median",
    missing_group_fallback="global",
    max_missing_fraction=0.2,
)
```

不传 `enhancements` 时，v2 仅在暴露构建器内修正非线性规模；Beta/残差波动率的
修正通过 `paired_market_descriptors` 显式提供。构建器不会自行读取价格或替换外部输入。
行业分类必须由历史分类表产生，不能用今天的分类回填。v1 的暴露数值、来源字符串和
溯源哈希与原构建器一致；新增配置键不混入 v1 的来源哈希。

`annual_growth_descriptors` 接受含 `asset, field, report_period, value, available_at`
的长表，`field` 为 `revenue_ytd` / `profit_ytd`，只取 12 月 31 日年报。
它同时返回描述子矩阵和质量矩阵；不替调用方推定公告日。

## 全市场计算与缓存

```text
quant-risk build-exposures --input exposures.json --out runs/day-a --cache-dir cache/exposures
quant-risk build-exposures --input exposures.json --out runs/day-b --cache-dir cache/exposures
quant-risk verify-research --run runs/day-b
```

同一市场截面先计算一次，多个组合复用相同日暴露。CLI 缓存键绑定完整输入、
配置、截止时间和相关代码文件；输入或定义变化产生新键。缓存内容有摘要校验、
原子写入和可用时间检查。`verify-research` 仍从输入独立重算，不依赖缓存。
`DailyExposureStore` 也可供每日任务使用，但调用方必须提供真实分区和代码的摘要。

风险模型保存 `X、F、D`，组合风险直接计算
`(X' w)' F (X' w) + sum(w² D)`。正常拟合、持仓查询和个股方差查询不生成 N×N 股票
协方差。显式访问 `asset_covariance` 或默认 `to_dict()` 仍会生成完整矩阵，以保留导出
接口；大截面导出请使用 `to_dict(include_asset_covariance=False)`。

缓存不证明数据源真实性，也不会自动检测尚未提供给系统的供应商修订。
首次历史回补与每日增量处理分开；本次基准不代表全历史重建或 PDF 下载速度。

## 实验设计与当前判断

固定原有 200 只历史股票；不因后来退市而更换样本。2023 年用于选择，2024–2025 年
已在上轮研究中查看，只作诊断。候选为旧定义、口径修正版、分别加入流动性/成长/
残差波动率、全部叠加、只使用可用成长描述子，共七组。

主对照使用相同 OLS、行业约束、股票/日期和组合；固定上轮增强风险估计器做敏感性
检查，不重新调风险参数。QLIKE 越低越好。按预测日期做移动区块 bootstrap，五个可选
增强使用 Bonferroni 校正；选择要求至少 40 个完整五日预测，区间上界小于零，波动偏差
和覆盖率通过门槛。任何组合持仓终点缺失都会使该日期退出共同完整样本，不重新归一。

原始年报补充得到 183 家公司的 386 条早期年度事实，解析冲突和缺失保留在审计中。
2023 年收入成长原始覆盖率约 87.0%，利润成长约 89.4%。可用组合是缺失处理能力，
并不因此自动成为更好的风险因子。

口径修正有独立的必要性：2023 年非线性规模的相邻日截面秩相关均值由 0.9432
提高到 0.9987，且通过市值单位不变性测试。它与旧非线性规模的相关性仅约 0.4082，
因此必须保留版本边界，不能无提示替换已有暴露或限额阈值。

| 候选相对口径修正版 | 2023 OLS 平均 QLIKE 差 | 2024–2025 OLS 差 | 处理 |
| --- | ---: | ---: | --- |
| 多期限流动性 | +0.003762 | +0.000776 | 未通过开发期筛选 |
| 收入/利润三年成长 | +0.001994 | -0.003441 | 未通过开发期筛选 |
| 仅可用成长描述子 | +0.002420 | -0.003526 | 未通过开发期筛选 |
| 残差波动率组合 | -0.002056 | +0.001517 | 开发期选中，保持研究候选 |
| 全部叠加 | +0.003009 | -0.001013 | 未通过开发期筛选 |

开发期有 44 个完整预测日期，残差波动率候选的校正区间为
[-0.003022, -0.001146]。已看过的 2024–2025 年有 79 个完整日期，
该候选区间 [-0.004768, +0.005009] 跨零；在固定增强估计器下平均差为 -0.004191，
区间同样跨零。不能把开发期通过说成稳定的样本外优势。

2026 年确认期保持冻结选择，并要求至少 80 个不重叠五日完整预测；截至 9 月底
不足以达到这一数量。研究完成与默认模型切换分别验收，不因样本不足降低门槛。

## 容量与验证

在本机以合成股票截面、21 个因子测得：

| 股票数 | 单日暴露构建 | 100 持仓组合查询中位数 | Python 跟踪峰值内存 |
| ---: | ---: | ---: | ---: |
| 200 | 0.128 秒 | 0.0065 秒 | 0.82 MiB |
| 1,000 | 0.384 秒 | 0.0176 秒 | 3.42 MiB |
| 6,000 | 2.037 秒 | 0.0845 秒 | 19.78 MiB |

这是暴露构建和因子化查询测试，不含网络、财报解析、滚动历史拟合；内存为
`tracemalloc` 统计而非进程 RSS。真实全市场覆盖和运行时间不能由合成规模测试直接推出。

6,000 只股票的单日日缓存约 5.51 MiB，包含暴露和完整处理溯源。

自动测试覆盖单位换算不变性、最终正交性、相同配对样本、未来数据污染不改变过去、
财报修订和负利润、成长缺失审计、缓存失效/损坏/独立重算，以及不访问稠密协方差的
组合风险恒等式。研究测试额外覆盖共同完整日期、冻结门槛、历史缓存来源校验。

复现命令及本地证据目录见 `research/public_a_share/README.md`。所有市场结果限于
这个固定样本与公开数据重建；未声称复刻商业 Barra 或拥有当年留存的完整市场数据快照。
