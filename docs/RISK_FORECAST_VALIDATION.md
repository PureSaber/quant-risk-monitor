# 逐期风险预测校验

此入口把期初风险预测与随后成熟的收益分开，评价固定模型的组合风险、相对基准风险和单资产总风险。
`complete`只表示所有请求均成功评分，不代表模型校准通过，也不会修改仓位、风险限制或模型参数。

```sh
quant-risk validate-forecasts --input examples/risk_forecast_study.json --out runs/risk-example
quant-risk verify-forecasts --run runs/risk-example
```

示例是三资产、四个训练期、四个预测期的合成数据。输出目录必须不存在。
成功返回0；数据、证据或重算失败返回2，并显示`unavailable`及原因。

## 输入与时间

输入JSON使用`quant-risk.forecast-study/v1`，包含`evidence_kind`、`frequency`、`config`、
`lookback`、`exposures`、`returns`、`requests`和`evaluation_as_of`，拒绝未知顶层字段。

- `evidence_kind`必须明确为`synthetic`、`retrospective`或`historical_pit`。这是调用方提供的来源分类；
  时间过滤与哈希不能认证外部来源真实性，也不能把今天下载的历史数据变成历史已知数据。
- 暴露的`values`按因子→资产组织，收益按资产组织。所有时点带时区，内部转换为UTC。
- 每个请求明确`period_start`、`period_end`、`weights_available_at`、`weights`、`source`，
  可附`benchmark_weights`。组合和基准权重必须都在期初已知。
- 训练只使用期初前已结束且已可得的收益，最多取最近`lookback`期；
  每期截面回归继续使用该期开始时已经有效且可得的暴露，不以事后修订重写过去。
- 预测期限为调用方声明频率的一个观测期；交易日周五到周一仍可为一期。
  程序不根据自然日差自动缩放，也不认证输入是否符合交易所日历。多期风险必须另建匹配模型。
- 评分收益必须与预测起止时间完全相同，并在`evaluation_as_of`前结束且可得。
  区间重复或重叠、缺少任一期结果、资产覆盖不全均拒绝，不删除不利观测后评分。
- 同一次评价固定模型配置、回看期数、资产集合及是否包含基准；权重可以随请求变化。

权重为期初净资产占比，一期内保持份额对应的期初权重计分。未分配现金按零收益处理，
负现金、杠杆及做空也不计融资或借券费用；因此本入口不是交易账户净收益校准。
全现金须显式提供至少一个资产的零权重；未知非零持仓由原生模型拒绝。

## 指标

原生模型给出年化资产协方差Σ，年化系数为A。一期组合方差为`wᵀΣw/A`，
主动方差以`w-b`替换`w`；资产方差为Σ的对角项除以A。只除一次，不重复年化。

一期组合收益为`wᵀr`，主动收益为`(w-b)ᵀr`。在显式条件均值为零的假设下，平方收益
是方差的有噪声代理，不是观测到的潜在方差。

|指标|定义与用途|
|---|---|
|标准化收益|`z=r/√v`，逐期检视预测风险与结果|
|bias statistic|`std(z, ddof=1)`，理想尺度接近1；不自动设通过阈值|
|标准化均值、RMS|分别保留平均方向与二阶大小，避免只看去均值后的标准差|
|方差MSE|`mean((r²-v)²)`|
|QLIKE|`log(v)+r²/v`；省略只依赖观测的项，仅适合同一收益序列的匹配比较|
|实际年化波动|`std(r, ddof=1)×√A`，描述评价期结果|
|预测RMS年化波动|`√(mean(v)×A)`，不是各期波动率的简单平均|

QLIKE可以为负，其绝对值不是通过分数，也不能跨不同收益单位或不同样本直接排名。
只有一期时，样本标准差不可用。若任何预测方差为零，该期保留在评分中，
该序列的标准化汇总及QLIKE均标记不可用；另计零方差但非零收益次数。
不添加epsilon，也不只计算剩余正方差样本。溢出和非有限值拒绝输出。

单资产检验针对**总方差**，不能据此宣称已独立验证潜在特异风险。
均值、残差相关性、分布尾部、估计不确定性和结构变化仍需独立研究。
这里不做统计显著性认证、参数搜索、自动校准乘子或样本外有效性声明。

方法参考：[MSCI/Barra风险预测偏差统计](https://www.msci.com/documents/10199/2c6649a3-e9de-4170-9bf7-3eb364264808)、
[Patton(2011)，不完美波动代理下的预测比较](https://public.econ.duke.edu/~ap172/Patton_vol_proxies_JoE_2011.pdf)。
独立实现的线性模型不代表授权MSCI产品，`statistical_proxy`分类始终保留。

## 产物与复核

输出恰好包含原始`input.json`、完整模型及预测`forecasts.json`、结果`evaluation.json`、
逐期`scores.csv`与`manifest.json`。预测保存模型、训练范围、权重时点和输入摘要。
运行期间源输入变化会失败；输出不会覆盖旧研究。

`verify-forecasts`读取固定文件集合的单次字节快照，校验哈希后从原输入重建所有预测和评分，
逐值比较JSON、逐字节比较CSV，再检查文件是否在核验期间改变。多文件、缺文件、符号链接、
模型恒等式不一致及重算不一致均拒绝。修改分数并同时重写清单哈希也无法通过原输入重算。
全部输入与结果被一致替换后，哈希本身不能证明作者身份；需要外部冻结登记或受信来源绑定。

Python调用可用`RiskForecastRequest`、`forecast_factor_risk`和`evaluate_risk_forecasts`：
先生成期初预测，随后提供成熟收益评分。直接API检查模型一致性，但完整原始输入复算由
上述研究文件入口负责。实际前向还需要独立记录预测发布时间、输入来源及不可变登记。
